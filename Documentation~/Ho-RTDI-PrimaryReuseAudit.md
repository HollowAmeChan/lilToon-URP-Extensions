# Ho-RTDI：弱灯主样本复用对照

第90步仅 Editor 诊断。沿生产 Runtime triple、初始8候选、历史预算4、空间4邻居/半径16，固定原三彩灯128²动态fixture，分别两复用、无复用、仅时间、仅空间。NRD保持开启，raw3%/filtered5%/dark .001 门槛不变。古堡不参与该解析验收。

核对用户 fork 的 `RayTracing/DI/GenerateInitialSamples.hlsl`、SDK `DI/TemporalResampling.hlsl` 和 `SpatialResampling.hlsl`：初始每16²像素共享一次RIS tile选择，之后时间/空间对候选重估target与归一化。只有复用开关变化，辅助fresh样本序列和CDF保持。

100:1阶段共96帧，前16帧不计入能量/方差。256固定点逐点计算红色输出除以该点解析红能量的Welford时间样本方差，再跨点平均；没有把空间亮度梯度混入时间方差，也没有把每像素时间方差当作整幅平均的误差置信区间。另输出五个16帧主样本能量区块。

两复用compat与RG报告一致。五个实际进程全部exit1，真实保留正式失败：两复用100:1失败；无复用100:1及redSpot失败；单独时间/空间100:1通过但redSpot分别raw红1.049863/1.032162超3%。因此不能通过关某种复用宣称整体修好。

两复用的五个primary块均值1.0544/1.1447/1.3479/1.2213/1.5497；无复用1.1409/.8668/.9365/.7687/1.1212。当前序列两复用提高弱灯方差及有限窗口误差，但并未计算自相关或多独立种子置信区间，不能据这五个均值证明系统偏差或确切相关时间。第89步长观察接近解析值仍成立。

实际采样身份、CDF、compact可见性、CPU解析遮挡和packed shade分解检查保持。Roslyn errors0，五日志无新增shader warning/error/SourceAssetDB时间错误，diff通过。报告为隔离工程 `rtdi-reuse90-{both,none,temporal,spatial}-cutout-rg.json` 与 `both-cutout-compat.json`。

不修改生产复用默认值。下一项可以隔离降低初始RIS tile的像素共享范围，验证是否改善局部弱灯有限窗口统计；用户fork的16像素范围是缓存一致性选择，改变它可能损失缓存效率，必须保持PDF/预算并独立测试其它灯域，不能仅凭该弱灯序列生产化。

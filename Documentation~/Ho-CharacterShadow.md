# Ho Shadows 角色局部阴影

角色局部阴影为主方向光提供更细的近身投影。Ho Shadows 按角色接收盒分配局部深度图块，并把固定 PCF 的可见度写入当前相机的主光产品。匹配接收组和深度的表面使用该结果。角色盒外继续接收原生主光阴影。

场景几何、其他角色和离屏遮挡物都可以参与投影，由主方向光的投射规则决定。环境 SH、APV 和间接漫反射沿用各材质的光照设置。

## 设置角色

1. 在相机的 `Ho Shadows` Feature 中启用角色局部阴影。确认场景主方向光和 URP 主光阴影已启用。[Ho Shadows 使用说明](Ho-Shadows.md)
2. 在角色根部添加 `Rendering/Ho-CharacterShadow`，指定已有的 ObjectBuffer 组。接收范围默认为整组。使用指定部件时，至少选中一个实际接收部件。
3. 使用「从接收对象计算包围盒」取得当前姿态的范围，再为动作调整 Anchor、Center 和 Size。较大的接收盒覆盖更多动作，也会减少每米的图集 texel 数。
4. 需要逐镜头调整时，在 `Ho-CharacterShadow Volume` 覆盖角色是否参与、期望分辨率或选择相应的调试视图。

## 分辨率与偏移

| 项目 | 默认值 | 用途 |
| --- | --- | --- |
| 单角色分辨率 | 2048 | 每个接收域的方形深度图块，可选 512、1024、2048、4096。 |
| 同时接收域上限 | 16 | 图集空间不足时，超出部分继续使用原生主光阴影。 |
| 图集边长上限 | 8192 | 可调至 16384，受到设备支持尺寸约束。 |
| 深度偏移与法线偏移 | 各 1 texel | 控制生成阶段的 caster bias。贴面投影消失时可检查偏移和实际投影分辨率。 |

角色解析使用固定九点 PCF，并按图块边界限制采样。角色投影的软边由图块分辨率、盒尺寸和固定采样半径共同决定。旧场景换用固定滤波后可使用同一保存机位对照软边和轮廓细节。

## 调试

Volume 的 Atlas 视图显示整张图集，Character 视图放大角色图块，All 使用公共平铺。Scene View 和 Game View 各有独立显示开关。先确认角色盒和接收组，再观察贴面投影、相邻角色和角色盒边界。图集生成的 GPU 标记与屏幕解析分别计时。整帧开销还取决于相机数、接收覆盖率和参与投影的几何。

`lilToon.URP.Extensions.Editor.CharacterShadow.HoCharacterShadowValidation.ValidatePcf` 可在隔离 Unity 工程验证固定滤波、核心可见度和图块边界。旧滤波的基线和运行说明保留在当时的版本中，供退役前后的对照重放。[历史对照片段](../Tests~/CharacterShadow/Optimization-20261123/README.md)

# ScreenProcess 镜头效果

## 光斑变焦

在 Ho-ScreenProcess 的效果浏览器添加「光斑变焦」。它是独立效果，不要求存在或开启景深层，也不读取 Camera.main 或 Camera 的物理镜头参数。

固定对焦与目标跟焦使用本层参数。目标跟焦支持吸取当前选择、场景层级路径与偏移；目标缺失时保留本层备用对焦距离。Game / Scene View 分别按当前渲染相机计算目标在相机前向轴上的距离。

焦距、光圈、失焦响应与合焦范围共同控制拉伸响应；前景作用、远景作用可以独立设为零。这里沿用现有景深的艺术化镜头响应，不宣称是完整物理镜头或曝光期间的真实变焦积分。后续公共镜头输入见 `计划/Ho-ScreenProcess-Lens-Plan.md`，本次不接入。

| 槽 | 内容 |
| --- | --- |
| `parameters0` | 对焦模式（0 固定 / 1 目标）、焦点距离、焦距 mm、光圈 f-number |
| `parameters1` | 变焦拉伸、亮部阈值、阈值柔化、光斑曝光 |
| `parameters2` | 中心 X/Y（-1..1）、亮度衰减、质量（8/16/32 tap） |
| `parameters3` | 失焦响应、前景作用、远景作用、失焦曲线 |
| `parameters4` | 叶片数、曲率、旋转、色散 |
| `parameters5` | 光斑增益、只显示光斑层、合焦半范围（米）、预留 |

跟焦字段为 `bokehZoomFocusTarget` / `bokehZoomFocusTargetPath` / `bokehZoomFocusOffset`，与景深字段互不关联。变焦中心不随跟焦目标移动，并支持 Game View 中心/拉伸手柄。

使用 `ScreenProcessDepthInputs.hlsl` 的主体、描边视觉深度与 URP camera depth 回退。输出像素按本身失焦量控制作用；每个颜色双线性邻点再单独检查源深度，避免把合焦人物/描边拉进远景光斑。色散各通道也走同一检查。

使用共享 SP/IP 混合表，默认相加；层遮罩与调试沿用 SP 行为，保留原图 alpha。缺失所有深度输入时保留原图。只显示光斑层时，有效深度中的合焦位置输出黑色。

## 景深内的光圈散景

在 Bokeh / 目标跟焦 Bokeh 景深中开启「光圈散景增强」。它使用该层已有的焦点、CoC、最大模糊半径和叶片形状，不新增独立效果类型。Gaussian 模式不启用增强。

- `parameters4 = (启用, 亮部阈值, 阈值柔化, 光斑增益)`。
- `parameters5 = (光斑曝光, 光斑硬度, 色散, 只显示光斑层)`。
- `parameters2.w` 保存光斑混合模式，使用共享编号；Inspector 暴露相加 / 滤色 / 叠加 / 替换。
- `color` 仅用于增强的光斑染色。

亮部增强直接累计在现有 CoC reach 检查后的采样上；默认关闭时保留原景深路径。合焦区域不产生扩散光斑。关闭色散时复用已取得的颜色/深度结果；开启色散增加受深度约束的红蓝采样，不增加独立全屏 RT 链。原有描边 coverage 与逐颜色邻点契约见 `DepthOfField.md`。

## 旧 ImageProcess 配置

ImageProcess 浏览器不再提供两个效果的新建入口，已有旧图层保留原 shader 与枚举编号，避免打开旧场景时静默改变画面。

含旧镜头图层的 Inspector 提供「迁移旧镜头效果到同一 Profile 的 ScreenProcess」，可撤销。迁移转存参数并移除已成功转换的 IP 图层，保留其他图层；旧自定义材质 / Shader override / 非零 passIndex 不自动解释，继续在 IP 运行。

旧光斑变焦迁为独立 SP 图层，附本层默认镜头参数。旧光圈散景迁为开启增强的 Bokeh 景深层，不覆盖已有景深层。旧光圈半径按原降采样倍率换算为全分辨率半径；原边缘提取不迁入景深，增强仅面向失焦亮部；叶片数按当前景深上限 9 钳制。

这是明确的效果语义转换，不保证旧全屏叠加与新深度效果逐像素一致。迁移后检查焦点距离、焦距、光圈、图层顺序与 SP 栈启用状态。没有可持久化 Profile 的临时运行时栈不显示可执行的迁移按钮。

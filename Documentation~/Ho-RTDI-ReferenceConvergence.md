# Ho-RTDI：参考工程收敛对照与静止历史修复

2026-10-18交付。参考工程的真实 DI、RELAX 和 DLSS RR 已在本机运行；对照确认，原始采样波动接近，当前主要差距在信号重建。Ho-RTDI 已接入静止/变化两种历史预算，固定夹具静止噪声方差约降至旧版的 **1/19**。这项修复不等于所有 RTDI 画质门槛或最终材质合成完成。

复现步骤、参考探针和 NRI 兼容补丁见 [Reference/README](../Tests~/RTDI/Reference/README.md)。23份原始 JSON、源文件/二进制哈希和已知失败分别保存在该目录的 `results/` 与 `evidence.json`。运行 `python Tests~/RTDI/Reference/verify_convergence.py` 会核对改进与失败记录，不把诊断进程成功当作全产品质量通过。

## 参考工程先修到实际可用

使用本机 `.codex-research/UnityPathTracing-6000.3.15`，Unity6000.3.15f1、D3D12、RTX4060。最初的三处问题有实际启动/渲染证据：

1. `PrepareLight.dll` 的依赖搜索不到包目录中的 `dxcompiler.dll`。仅为启动的参考 Unity 进程提供两个插件目录的 PATH，没有改系统环境变量。
2. 固定 NRI 在启用 Agility 编译时，无运行时接口检查就调用 `ID3D12Device15::TryCreate*`。当前 Unity 设备不具备该接口，首次创建 SRV 时触发错误/原生退出。六处描述符入口增加实际设备版本检查；保留新接口路径，较旧设备使用其支持的创建接口。Sampler2另保留版本11及传统 sampler 的分支。补丁只进入隔离参考的 NRI.dll，不修改 Unity.exe、系统 D3D12 或包内 HoRTDINRD.dll。
3. Native参考的合成 shader 没有 `WITH_NRD`。即使 C# 调度 NRD，最终合成仍编译为读取 raw。补齐宏和明确的本地 NRD include/编码配置，再重新导入相关 shader 后，实际最终输出才消费 RELAX。

Native几何需要登记 `NativeRayTracingTarget`，探针显式添加。最终 Unity raw/RR 基准执行原始空发光网格准备 pass，报告 `emptyEmitterGuard=false`；早期跳过空 pass 的启动诊断没有充当最终基准。参考核对使用的是实际输出纹理，不是一个本来就未写入的 debug texture。

包内固定 NRD 4.17.3 CPU DLL 与参考 NRD.dll 仍具有相同 SHA；原SDK、四份派生重建检查及现有输入/输出布局未因本修复改变。

## 同场景、同采样预算

固定128²、透视FOV40、相机 `(0,0,-3)`、白色非金属平面、粗糙度约.5、F0约.04；红/蓝两盏delta point位于 `(±1.5,0,-1)`，强度4、range100。局部候选8、ReSTIR时间历史4、空间4样本/半径16、ray-traced correction，最终单样本。关闭环境、GI、jitter与PT累积。

参考与本地仍有量化、RNG和既有镜面重要性目标的差异，不能声称逐位相同。另保留一条在 **完全相同 Ho 输入** 上运行原版RELAX shader/默认参数的对照，专门分离重建差异。

统计每个固定ROI像素的RGB时间方差，避免将空间渐变/纹理当噪声。表中为第257—512帧窗口，方差以该窗口逐分量均值的平方和归一；不是FPS或完整图像误差。

本次Ho残余时间方差仍约为参考RELAX的2倍、RR的5.7倍。原版预滤波/派生material与颜色边界处理不同；当前结果没有证明所有高频细节、遮挡和HDR场景都已达到参考画质。

## 生产修复

实际渲染时检查当前/前次相机矩阵、世界Revision、真实解析灯数值快照和历史重置事件。持续半秒没有这些变化时，漫反射主历史由约50ms切换至参考量级的500ms；快速漫反射历史、镜面历史、采样预算、空间滤波与资源均保留。

离开稳定状态时，NRD历史重启一次并回到原响应优先预算；连续运动继续沿原可见性confidence处理。变化停止后留出半秒响应窗口，再使用较长历史。它不会在每个运动帧都清NRD，也不会为了静止稳定增加最终射线、GPU纹理或新的用户设置。

预算按相机实际unscaled采样时间和既有FPS低通换算，不按渲染请求数伪造时间。30/60/120Hz、倒退/无效时间及同一时间重复请求的状态检查均通过。Editor测试的时间覆盖会暂时退出，避免把覆盖值误当传入自检时间；修正后的自检在两路径实际重跑通过。

静止判定目前是逐相机的全局状态：持续更新的相机、光源或几何会保持原短预算，即使画面中的部分区域没有变化。它还不是逐像素区分静态区域与动态角色的长历史方案。

## 动态与部署证据

- 固定60Hz漫反射 slow/rapid 继续通过。严格 casterStep 的变化区前三帧误差由短历史对照 `.357736` 降为 `.350414`，仍高于原 `.35` 门槛；两条路径都明确失败，没有调高门槛。它属于新协议下基线也存在的失败，不记成已修复。
- 独立镜面三项运动、实际Triple解析灯变化两路径各9/9、默认Single复用噪声16配置、primary运动6配置通过。
- 原环境测试两路径仍各2/4，mixed镜面filtered偏差保留。该问题与本次静止漫反射方差改善分别记账。
- 两个Win64 Mono release构建成功，实际RG/compat默认suite通过，DX11实际inactive通过。
- 新增 `--convergence` Player测试跨192个真实应用帧执行，不使用Editor时间覆盖。实际进入长历史，变色后回到短历史且仅一次重启，四帧后旧红色残留为0。它验证了时间策略已部署；不是TAA/XR或物体运动向量源验收。

直接把历史固定加长、按单像素confidence压预算或重置共享age的试验，没有同时守住动态门槛，均未进入生产；相应生成器已移除，失败数值保留在审计记录中。

## 使用与剩余限制

需要开启 Ho-RTDI 的可选NRD，并查看发布的 diffuse/specular 或对应filtered调试输出。Raw输出保留原随机样本，默认NRD开关仍关闭；本次没有自动改写用户场景资产。

最终lilToon材质合成、正常应用帧的物体运动向量、lobe命中距离代表性、实际场景完整画质和可信GPU预算仍未交付。本次完成的是参考链路复现、明确差异定位和有实际收益的静止历史修复。

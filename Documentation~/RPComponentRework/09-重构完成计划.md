# 重构完成总结

> 2026-05-26 收口版。本文只记录当前事实、验收结果和后续边界。

## 0. 结论

本轮 RPComponentRework 已完成。Runtime / Editor / shader 主路径不再以旧 `HoAOV`、`HoPost`、`ShoostStack` 作为概念入口。用户侧入口收敛为：

`ShadowCast`、`MetadataBuffer`、`GeometryBuffer`、`SSS`、`OIT`、`CharacterSpecialization`、`ScreenProcess`、`ImageProcess`、`DebugTile`。

当前使用顺序以 `07-用户向RendererFeature使用与顺序.md` 为准。旧 `Documentation~/PostProcessing/` 只作为历史资料。

## 1. 当前事实

- `ImageProcess` 是最终图像链，只处理 camera color / ImageChain，不读取 MetadataBuffer、GeometryBuffer、ShadowCast、SSS、OIT 或 CharacterSpecialization。
- `ScreenProcess` 是语义屏幕处理层，按 active layer 聚合 MetadataBuffer / GeometryBuffer 真实需求；缺失项通过 Volume Inspector runtime status 暴露。Rule mask debug 保留 layer-local 直出，不做 RendererFeature 级 debug pass。
- `MetadataBuffer` / `GeometryBuffer` 已拆成独立 RendererFeature。MetadataBuffer 只表达 mask、object、material、surface metadata；depth / normal 归 GeometryBuffer。
- `ShadowCast` 是 Lighting/Shadow 组件，从 URP visibleLights 自动收集额外投影灯；旧 controller / manual list 已删除。
- `SSS`、`CharacterSpecialization`、`ScreenProcess` 只消费自己真实需要的 Buffer 项，并在缺依赖时暴露诊断。
- `DebugTile` 由 `HoDebugViewRegistry` 自动生成 tile，总览 MetadataBuffer、GeometryBuffer、ShadowCast、SSS；ScreenProcess rule mask 仍由 layer-local debug 输出。
- RenderGraph 是主线。compatibility path 如保留，只作为非 RG fallback；ImageProcess、ShadowCast、Buffer、ScreenProcess、CharacterSpecialization、SSS、OIT 的 compatibility-only RT / camera target 状态已从 RDG 主线剥离。

## 2. 验收结果

- Runtime / Editor / shader / asmdef / json 扫描：`HoAOV`、`HoAov`、`HoPost`、`ShoostStack`、`NeedsAovInput`、`_lilHoAov`、`HoAOVSSS` 无命中。
- 旧名只出现在历史文档或迁移记录中。
- `Documentation~/PostProcessing/README.md` 和相关旧文档已标记历史资料。
- `07` 已标明当前 RendererFeature 顺序是最终用户说明，不是迁移期建议。
- 当前仓库无 `.sln` / `.csproj`，未执行 C# 编译；后续需要 Unity 工程实机验收。

## 3. 后续边界

不再继续按旧兼容小项扩散。后续只保留：

- P2 未来能力：`GeometryBuffer.Motion/Velocity`、`MaterialBuffer.RoughnessLike/SmoothnessLike/EmissionHint`、`ShadowCast` ScreenProcess receiver 等，必须有真实消费者后另开任务。
- Unity 实机验收：RendererFeature 顺序、Frame Debugger、DebugTile、典型材质 / 透明 / SSS / ScreenProcess 场景。
- 文档维护：用户向 UI 文案、RendererFeature 默认值或新增能力变化时同步 `07` 和对应组件文档。

## 4. 最终摘要

这轮重构已经从“旧 AOV / HoPost / Shoost 兼容迁移”转为新的组件边界：Buffer 负责语义输入，ScreenProcess 负责语义屏幕效果，ImageProcess 负责最终画面链，ShadowCast 独立负责额外投影光源，debug / tile 只编排 feature-local view。当前主线可以收束。

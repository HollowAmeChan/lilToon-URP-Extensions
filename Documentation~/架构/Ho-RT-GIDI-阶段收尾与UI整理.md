| 项目 | 现状与证据 | 本阶段处置 |
| --- | --- | --- |
| RTDI 直接光 | 解析灯、直接天空、diffuse/specular、世界遮挡、可选 NRD 与正常相机替换/加法合成已接通；见 [RTDI](../Ho-RTDI.md) | 固定默认与现有行为，整理使用入口 |
| RTGI 间接光 | 一跳 diffuse、次级材质/灯/天空、基础 Cutout、骨骼快照、独立 NRD 和加法合成已有验证 | 固定当前生产算法与保守失效策略 |
| 真实 Player 呈现 | GI 两路径各 240 次自动相机回调、512²默认屏幕输出、开关/移动/发光响应与截图，见 [Backbuffer](../../Tests~/RTGI/Backbuffer/README.md) | 已补齐早期“只有请求式渲染”的缺口；不推广为复杂场景矩阵 |
| 公共 NRD 与资源 | A01 解耦；A02 输入/发布顺序复用，两路径逐位相同、Release 304 请求通过 | 架构轻量阶段已结束；默认省 8 B/像素，1080布局约 15.82 MiB/相机，非整帧显存实测 |
| GI filtered 质量 | 全域/局部原门槛仍有失败；046 confidence 候选无已证明收益，未进生产 | 保留失败与 raw 对照；047 reference 草稿搁置 |

## 组合接入

1. 使用已验证的 Win64 Mono / D3D12 DXR 环境；先提供同分辨率、单采样 GB/SB，需要天空时启用 Ho-Atmosphere。Renderer 通常按输入生产者 → RTDI → RTGI 排列。
2. **DI**：Feature 开生产总开关，Volume 的“启用”必须勾选覆盖并打开。画面、降噪、采样质量和天空强度在 DI Volume；几何/灯筛选、排除材质与 Shader 在 Feature。
3. **GI**：Feature 开生产总开关；Volume 可覆盖启用、降噪、合成和间接光强度，未覆盖时沿用 Feature。当前 GI 的采样和天空设置仍在 Feature，不能按 DI 的显式启用覆盖规则推断 GI。
4. 先分别确认 Receiver，再看 Diffuse / Specular，最后打开正常画面合成。调试与合成相互独立，Raw 有噪点不表示 NRD 未运行。ReSTIR 历史上限不等于 NRD 历史帧数。
5. DI 与 GI 同用时，主表面直接天空交给 DI，GI 的“额外包含主表面直接天空”保持关闭；次级天空保留。GI 独立使用时才按照明归属显式选择直接天空。
6. DI 加法保留原直接光，GI 加法也保留原有烘焙/探针/SSGI；这属于可调的艺术叠加，不会自动替换原照明。DI 参考 PBR 替换与 GI 一跳加法各自按其合同工作。

## 本轮修改前 review

本轮只做文档与 Editor 展示：修正 GI 入口过时的 active/自动相机状态及 NRD 资源说明；GI Feature 分为基础、采样质量、天空照明、高级，Volume 分为运行、画面合成、调试。统一“生产总开关”“ReSTIR 历史上限”“邻域半径（像素）”与中文调试标签，保留字段、序列化路径、参数范围和默认值。

不在本轮把 GI 的采样参数迁入 Volume：那会改变逐相机解析、旧资产回退、不可变设置快照和历史签名，需要单独的兼容步骤。也不统一 DI/GI 启用语义、不自动开降噪或合成、不移动公共 Shader/asmdef、不合并两路历史。

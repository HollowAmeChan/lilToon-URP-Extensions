# Ho-RTDI 镜面中心偏差与全平面积分

> 状态：历史过程记录。本文的“当前”“下一项”和通过/失败数值均属于写作步骤，不是待自动执行的任务或现行全产品结论。现行入口：[Ho-RTDI 总文档](../../Ho-RTDI.md)。

第63步扩大第62步透视参考的空间评分。结果说明当前中心“偏亮”不是同幅全图增能，更明显的问题是空间滤波搬移解析高光。生产未改，中心质量门槛仍保留。

## 区域与独立读取

`RunPerspectiveAuxiliarySpatialBaseline`读原运行时，`RunPerspectiveAuxiliarySpatial/Compatibility`读三样本贡献分配原型。沿128²/FOV40、绿色常量天空、红蓝解析、透明Cutout、192预热/512观察与逐像素CPU交点/实际V/Smith GGX/斜视天空积分，分别无复用和T/S。

整个投影平面取|world x/y|<.995，13456个像素；每帧必须具有真实raw/published primary alpha。不是把背景或无关联像素作为有效接收面。嵌套中心64²/32²/16²分别4096/1024/256点，outer为整面扣inner64、annulus为inner64扣inner32，严格核对分解数量。原始与发布RGB积分、参考积分及绝对excess都记录，有限值异常直接失败。

这个all覆盖屏内有效平面，不等于整个任意场景或照明积分；像素面积与投影相同，暂不称世界表面积积分。min边界有小guard，过滤可能跨guard，所以全区域亏损不能直接等同算法严格不守恒。

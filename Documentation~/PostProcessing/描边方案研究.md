# 执行摘要

本文围绕 URP 中高质量的轮廓（描边）滤镜设计展开，重点支持深度+法线联合描边并具备 Mask 功能。我们首先比较几种描边算法：基于几何的“反向壳”绘制与基于屏幕空间的卷积边缘检测，并分析它们各自优缺点。例如，借助 Sobel 卷积在深度和法线纹理上检测边缘（如 Unity 示例所示）能同时捕获物体轮廓和凹凸细节【10†L411-L420】【28†L129-L138】；而几何膨胀方法实现简单（通过 Render Objects 功能对目标物体沿法线推顶点并剔除前面），但容易出现线宽不均匀和断裂等伪影【8†L199-L208】【12†L212-L220】。我们还讨论了在有 Mask 的场景下，屏幕空间卷积可能跨区域检测到不应出现的边缘，并介绍了一些解决方案：使用双通道/分步处理（如将 Mask 和非 Mask 区域分开计算边缘），对边界做扩展或深度偏移，设置法线阈值排除浅角边缘，以及在多尺度（multi-scale）和时域（temporal）上进行重投影平滑等技术。  

Mask 设计方面，常用方式包括利用图层（Layer）或渲染层、材质标签等将目标物体分组，通过摄像机特殊 Pass 生成对象ID/Section Map 或使用 Stencil/深度信息来定义 Mask。理想的 Mask 系统应支持手工绘制或程序生成（如语义分割）、在编辑器中可视化和实时调整。描边管线需根据 Mask 只对指定区域绘制轮廓，并避免因卷积取样而出现渗漏。  

对于艺术家参数，我们梳理出一系列常见可调控项并进行了分组：**轮廓检测**参数（如阈值、边缘宽度、深度/法线权重等）；**线条样式**（颜色、虚线/噪声纹理、渐变、角度依赖等）；**附加效果**（深度偏移、远近淡出、遮罩混合模式、抗锯齿、时域平滑等）。例如，一个典型 Sobel 边缘效果会暴露“边缘宽度 (Thickness)”、“深度权重/偏移”、“法线权重/偏移”、“阈值”和“边缘颜色/背景颜色”等参数【25†L106-L115】【32†L90-L95】。我们为参数提供了默认值范围建议，并给出了交互式调整的指导。参数群组以表格形式呈现，便于概览。  

实现架构方面，我们在 URP 中提出了两种可行的管线设计：**几何法**（基于 Render Objects 特性，对需要描边的物体使用专用的“反向外壳”材质渲染一次【12†L212-L220】）、**屏幕空间法**（基于 Blit 后处理特性，通过采样 _CameraDepthTexture_/_CameraNormalsTexture_ 并在自定义 Shader 中执行 Sobel 或拉普拉斯滤波【10†L452-L460】【25†L106-L115】）。流程图展示了大致流程：从捕获深度/法线纹理，到边缘检测合并，再到应用阈值和 Mask，最后合成输出（见下方 mermaid 图示）。关键算法（如 Sobel 卷积叠加深度和法线边缘）以伪代码形式给出。  

在示例与对比中，我们分析了 Pencil+ 参数设计的特点：Pencil+ 提供多种类型的边缘（最多可定义 8 种边缘类型），并为每种边缘设置独立的颜色和粗细，同时支持根据摄像机距离做线宽渐减【35†L99-L107】。这一思路可以借鉴到 Unity 中，例如为轮廓效果提供多层次的细节和距离衰减。我们给出两个可复制的预设案例——**铅笔素描风格**（细线、颜色淡灰、略带抖动）和**卡通风格描边**（粗黑线、颜色纯黑、均匀宽度），并说明了各参数的调整要点。  

最后，针对测试与验证，我们建议使用多种场景（几何简单与复杂物体、遮罩与非遮罩区域、近景与远景等）来检查轮廓的正确性和视觉效果。可准备不同类型的示例截图（如仅轮廓线、原图叠加轮廓、不同参数下对比图），并以这些为基准评估 Mask 准确度和艺术可控性。例如，通过对比无 Mask 时与 Mask 区域的轮廓输出，检验遮罩边缘无错漏；通过查看运动场景中的连贯性来评估 temporal 平滑效果。

## 1) 算法

**基于几何 vs 屏幕空间**：几何描边（如反向外壳法）通过对物体进行一次额外渲染，沿顶点法线推顶点并只渲染背面，能获得一致的边缘宽度且与材质无关【8†L215-L223】【12†L212-L220】。其优点是实现简单且无需依赖后处理。然而，它会产生一些问题：线宽在对象非均匀缩放或物体原点偏移时表现不一【8†L199-L208】；在非光滑（硬边）网格处会断裂【8†L247-L255】；且物体内表面（内部边）也会产生不必要的轮廓。这些缺陷难以完全修正（可以尝试剔除、Stencil 或深度偏移，但复杂度增加）【8†L273-L282】【12†L212-L220】。  

相比之下，屏幕空间图像卷积方法（Edge Detection）通过 Sobel、拉普拉斯等滤波器在渲染结果的深度图、法线图或颜色图上检测不连续，能捕捉物体的外轮廓和内部细节【10†L411-L420】【28†L129-L138】。以 Sobel 算子为例，其分别采样深度/法线图像周围像素并计算梯度，当梯度超过阈值时标记为边缘【10†L452-L460】【25†L106-L115】。深度图适合检测物体轮廓（图形外缘），法线图适合检测高曲率或折线部分【10†L411-L420】。此外，也可使用图像颜色（亮度）梯度检测纹理或着色突变，弥补深度/法线不足的边界。不同滤波器的选择（Sobel、拉普拉斯、Prewitt等）影响到边缘宽度和噪声敏感度，Sobel 计算量适中且常用，但拉普拉斯对噪声更敏感，需要在阈值和后处理上作权衡。    

**Mask 与卷积冲突**：当只想对特定区域或物体描边时，如果采用全局卷积，可能在 Mask 边界或遮挡处出现错边或漏边。常见的解决方案包括：

- **双通道/分步处理**：分别对 Mask 区域和非 Mask 区域进行边缘检测，然后合并结果，避免被遮挡物贡献错误边缘。  
- **边界扩展**：对 Mask 边缘进行扩充或膨胀，让滤波器在 Mask 边缘处也采到合理值，从而减轻边缘丢失。  
- **深度偏移**：在渲染 Mask 边缘物体时对其深度进行微调，使其与背景深度产生突变，从而在深度检测中自然产生边缘【8†L273-L282】。  
- **法线阈值**：设置一个法线差异阈值，只对超过该角度的边缘响应，从而过滤掉平滑表面的噪声边缘【28†L186-L194】。例如，Linework 插件提供“尖角屏蔽（Sharp Angle Mask）”选项，根据视角浅时减少边缘检测【28†L186-L194】。  
- **多尺度（Multi-Scale）**：对不同尺寸的卷积核或金字塔图像进行边缘检测，并融合结果，以同时获得粗与细的轮廓。  
- **时域重投影（Temporal Reprojection）**：在运动场景中，可以利用历史帧信息平滑边缘抖动，通过运动矢量将前帧边缘投影到当前帧，并与当前帧结果混合，提升稳定性（尤其对 VR/AR 场景重要）。  
- **其他方法**：跳跃泛洪算法（Jump Flooding）等 SDF 方法可用于非常宽的描边，但复杂度较高，目前主要为研究方向【14†L185-L194】。

综上，**基于图像卷积的描边**优势在于对所有物体一致，可捕获内部细节，可通过阈值和混合控制风格【10†L411-L420】【25†L106-L115】；缺点是全局成本较高，且对 Mask 管理要求更高。**基于几何的描边**简单直观，可精确对指定物体，但线宽难均匀且会出现断裂伪影【8†L247-L255】【12†L212-L220】。在实际应用中，两者常结合使用：例如 Unity Toon 示例中同时提供 Hull（几何）和 Post（屏幕）两种方案【12†L212-L220】。

## 2) Mask设计

**Mask 数据结构**：Mask 可以采用 **渲染图层（Render Layer）** 或 **Layer/Tag** 系统实现：将需要描边的物体归入特定层或赋予特定材质标签，然后在渲染过程中识别这些对象。也可使用 **Stencil Buffer**，即首先渲染需要描边的物体到模板缓冲，后续描边 Pass 中利用模板测试限制轮廓绘制。此外，**对象 ID/Section Map** 也是常见方式：为每个物体分配独特 ID，并渲染到额外纹理（Section Map）中，这样在后处理时可根据 ID 对某些对象应用不同的效果或排除【28†L178-L186】。

**生成策略**：Mask 通常可通过以下几种方式获得：  
- **手工绘制**：在场景编辑器中使用工具（如遮罩笔刷）直接在屏幕上绘制区域，用于场景特效标记或后期合成。但这种方式更多见于静帧或电影场景，游戏中少用。  
- **材质/标签**：给材质或对象添加特定标记（如自定义 Shader Tag），在渲染时检测标签以决定是否描边。  
- **层级/渲染层**：Unity 中通过设置物体所属 Layer，并在后处理时指定只对某些 Layer 进行描边。例如 Unity 示例的 Hull 方法可以对某些渲染层启用描边【12†L212-L220】。  
- **Stencil/Depth/ID 缓冲**：上文提到，利用模板缓冲（Stencil）或深度缓冲对特定物体分层渲染；或者使用顶点/像素颜色将 ID 信息输出到 G-Buffer/辅助渲染目标，后续据此控制描边。  
- **语义 Mask**：在高级应用中，可利用语义分割（如角色 vs 场景）生成 Mask，在描边中只选取特定语义对象轮廓，增强风格控制。  

**与描边算法的交互**：Mask 应在边缘检测前后发挥作用：若是屏幕卷积，应在后处理管线中加入判断，对非 Mask 区域直接输出原色，对 Mask 区域执行边缘检测。例如可先将 Mask 物体渲染到某个标识纹理，再在 Outline shader 中通过条件判断跳过或弱化非目标像素的边缘计算。对于 Hull 方法，Mask 本质上由渲染层决定，只对指定层的网格进行外壳渲染。要注意，Mask 边缘与邻域颜色/深度会影响卷积结果，上述算法技巧（边界扩展、深度偏移）都可用于 Mask 情况下提高准确度。

**Mask 编辑与可视化工具**：建议在编辑器中提供 Mask 预览功能，例如用叠加高亮显示被选物体轮廓、展示 Section Map 或深度图边缘，让艺术家实时看到修改效果。参数界面可列出 Mask 对象列表或纹理，并允许手动编辑（添加/移除物体、调整区域）。同时可提供热键查看当前帧的轮廓输出，仅轮廓线条或区域填色显示，帮助调试。类似 [28] 所示的 Section Map 配置界面，可让用户指定层、ID通道或纹理作为掩码输入【28†L178-L186】。总之，Mask 系统既要灵活多样，又要在 UI 上易于操作和可视化。

## 3) 艺术家参数集合与 UI

现代描边特效通常具有丰富的可调参数来满足各种艺术需求。我们将常见参数分为**轮廓检测**、**样式**和**附加效果**等类别，并给出默认值范围与说明（见下表）。主要参数包括：边缘阈值、线宽、颜色、虚线/噪声、深度/法线混合、渐变、角度依赖、Mask 混合、抗锯齿、时域平滑等。

|-------------|-------------------------|-----------------------|------------------|

## 4) 实现架构

在 URP 中实现深度+法线描边滤镜，常用方式是借助 **Scriptable Render Feature**。总体流程如下（图示为伪流程）：

```mermaid
graph LR
    A[开始摄像机渲染] --> B{选择描边方式}
    B -->|几何法 (Hull)| C[Render Objects Pass\n(对指定层的物体使用描边材质渲染)]
    B -->|屏幕法 (Post)| D[采集深度 & 法线纹理\n(Custom Pass 创建或使用内置纹理)]
    D --> E[全屏描边 Shader\n(对采样纹理进行 Sobel/Laplacian)]
    C --> F[合成轮廓]
    E --> F[合成轮廓]
    F --> G[抗锯齿处理 & 时域平滑]
    G --> H[输出最终图像]
```

- **Render Feature & Render Pass**：需要在 URP Asset 的 Renderer 中添加自定义 Feature。对于几何法，可使用 `Render Objects` 功能，为特定图层添加一个新的渲染对象通道，指定使用一个“推顶（Inverse Hull）”着色器（将顶点沿法线偏移，并剔除前面）渲染。对于屏幕法，可使用 `Blit` 功能，在不透明通道后插入一个后处理 Pass，以当前帧的深度/法线纹理为输入，输出到屏幕或临时 RT。  

- **Shader/Compute**：在后处理 Pass 的材质中编写 Shader。核心逻辑是对屏幕上的每个像素采样其邻域深度与法线，计算边缘强度。例如下面伪代码演示 Sobel 合成边缘：  

  ```glsl
  float depthEdge = Sobel(_CameraDepthTexture, uv, _OutlineThickness);
  float normalEdge = Sobel(_CameraNormalsTexture, uv, _OutlineThickness);
  float edge = depthEdge * depthWeight + normalEdge * normalWeight;
  if (edge > threshold) {
      // 认为是边缘线条，输出轮廓颜色
      return outlineColor;
  } else {
      // 非边缘，输出原始场景色
      return SAMPLE_TEXTURE2D(_MainTex, uv);
  }
  ```  

  上述伪代码中，`Sobel(texture, uv, size)` 表示对给定纹理在像素 `uv` 处进行 Sobel 卷积计算；`depthWeight`、`normalWeight` 是深度和法线边缘的混合权重【10†L452-L460】；`threshold` 是用户指定的边缘阈值【10†L452-L460】。实际实现会在 HLSL 中根据 Unity 提供的 DeclareDepthTexture/NormalsTexture 例程进行采样计算【8†L307-L315】【10†L452-L460】。  

- **G-Buffer / 额外 Render Targets**：如 URP 使用延迟模式，可直接在 GBuffer 中获取法线。然而 URP 通常先写深度+法线到屏幕空间纹理（可通过 `Depth Texture` 与 `Normals Texture` Pass 启用）。对于 Mask，可在该 Pass 中附加绘制 ID（如 `Object ID` Channel），或额外 render to texture。

- **Command Buffer 流程**：整体可分为：先渲染常规场景；然后执行自定义的图形命令（将需要描边对象渲染到 RT 或直接在屏幕进行全屏 Pass）；最后将轮廓结果与原始画面混合合成。示例代码中通常在 `ScriptableRenderPass.Execute()` 中通过 `cmd.Blit` 将输入纹理与轮廓 Shader 材质结合【25†L176-L185】。

具体伪代码框架如下：  

```csharp
public class OutlineRenderPass : ScriptableRenderPass {
    public Material outlineMat; // 持有边缘着色器材质
    public override void Execute(ScriptableRenderContext context, ref RenderingData data) {
        // 设置输入（深度纹理已声明自动可用）
        CommandBuffer cmd = CommandBufferPool.Get();
        // 传递参数给材质
        cmd.SetGlobalFloat("_OutlineThickness", settings.thickness);
        cmd.SetGlobalFloat("_DepthWeight", settings.depthWeight);
        cmd.SetGlobalFloat("_NormalWeight", settings.normalWeight);
        cmd.SetGlobalFloat("_Threshold", settings.threshold);
        cmd.SetGlobalColor("_OutlineColor", settings.color);
        // 全屏 Blit：从原始颜色到目标（可直接写回目标使其叠加）
        cmd.Blit(sourceTexId, destinationTexId, outlineMat, 0);
        context.ExecuteCommandBuffer(cmd);
        CommandBufferPool.Release(cmd);
    }
}
```  

请参见附图所示流程，以及以上伪代码说明。此处的关键逻辑与 Unity 官方示例（Sobel Outline）类似【10†L452-L460】【25†L106-L115】。

## 5) 示例与对比

**Pencil+ 参数设计借鉴**：Pencil+ 作为专业非真实感插件，提供了多层次的线条控制。例如其文档指出，Pencil+ 允许创建多个 **Line Set** 分组，将对象/材质分组后对每组设置线条参数【35†L99-L107】；每个 Line Set 包含独立的“画笔设置（Brush Settings）”，可以为不同类型的边（如轮廓线、隐藏线等，共可定义 8 种类型）指定颜色和粗细【35†L99-L107】。同时，Pencil+ 支持“Reduction”设置，根据摄像机距离动态缩放线宽，使远处线条自动变细【35†L99-L107】。这些模式值得借鉴：我们也可在工具中允许多重线条层次（例如外轮廓 vs 内部轮廓），并提供距离衰减选项来增强真实感。  

**参数预设**：基于上述讨论，我们给出两个可复用的参数预设，并简要说明调节思路：

- **铅笔素描风格**（轻柔速写）：线条较细但略带波纹感。建议**边缘宽度**较小（~1像素），**阈值**较低（0.05–0.1）以捕捉细节；**颜色**选用深灰或木炭黑，**背景颜色**淡灰以模拟纸张；启用**噪声/纹理**叠加（强度 ~0.2–0.5），并添加少许**抖动**或不规则性；可利用**渐变宽度**使远处线条更细。混合方式可使用叠加（便于在纸张上叠加线条）。调参时关注线条是否自然不齐整，必要时增加多重采样或虚线组件增加手绘感。

- **卡通风格描边**：线条黑白分明、粗犷简洁。设置**边缘宽度**较大（3像素以上），**颜色**纯黑；**阈值**适中（0.1–0.2）以过滤背景噪声；通常不加噪声（禁用纹理）；**深度权重**较高（接近1.0）突出物体轮廓，【10†L416-L424】保证外轮廓完整；**法线权重**可较低或中等，以捕获明显折角。可启用**Z 偏移**，防止轮廓线被前景遮挡。对于动态场景，可视情况添加**抗锯齿**或少量**时域平滑**，保持线条稳定清晰。  

以上预设仅为参考，实际效果依赖场景内容和艺术风格。一般流程为：先在简单模型（如球体、立方体）上测试线宽与阈值，再将效果应用到复杂场景以微调。Pencil+ 参数的多种边缘类型和距离调整启发我们在 Unity 工具中也可以提供“内边/外边”区分或“优先级（Priority）”设置，让艺术家对不同线条层次进行精细控制【35†L99-L107】。

## 6) 测试与验证

为保证效果质量，应设计**综合测试用例**并对比可视化结果：

- **简单几何物体**：使用基本形体（立方体、球体、圆柱等）测试各个边缘类型。检查外轮廓和内凹边界是否正确描出，避免如反向外壳法常见的“断裂”现象。【8†L247-L255】  
- **复杂模型**：在细节丰富的模型（如角色、建筑）上测试，以确保法线边缘和深度边缘兼顾。特别注意法线高光位置是否产生多余的内轮廓，适当调整法线阈值过滤浅角噪声【28†L186-L194】。  
- **Mask 精度**：构建含前后遮挡、半透明区域的场景，验证 Mask 区域边缘是否完整且不会向外溢出。可制作辅助渲染（如单独渲染 Mask 物体的轮廓）并与期望轮廓对比。  
- **不同距离**：使用远景与近景相机位置测试远近淡出效果，看线宽随距离变化是否符合预期【26†L99-L108】。  
- **动态场景**：在动画或移动摄像机下观察轮廓稳定性。评价是否需要时域平滑以及设定合适系数。  
- **参数对比图**：制作一组对比图，例如固定场景下调整阈值、厚度、深度权重等得到的差异图。也可对比添加/不添加噪声、虚线效果的视觉区别，帮助艺术家理解各参数影响。  

**示例截图类型**：建议生成以下几类图片用于评估：原始渲染图、仅轮廓线（背景全黑或全白）、轮廓叠加原图（平滑遮罩显示）。结合 Mask 的场景可以输出 Mask 显示图（不同物体或区域用不同颜色填充）以验证正确性。在文档或工具中，可将这些截图类型并列展示，让开发者和美术迅速定位问题。  

**评估指标**：主要从两个方面考量：*边缘准确度*和*艺术可控性*。准确度方面，可通过人工与几何学验证（轮廓线是否与模型轮廓、法线突变处吻合；Mask 边界是否有错漏线）来定性评估；也可编写脚本统计轮廓线与真值（如模型投影轮廓）的一致度。艺术可控性方面，则观察参数调节是否带来预期效果，如线条粗细、虚实变化是否直观。性能虽非首要考量，也应记录不同设置（如多通道边缘、抗锯齿）的耗时差异，并标注可优化点，如可选地禁用某些检查来提速。

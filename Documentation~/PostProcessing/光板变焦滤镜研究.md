# 光斑变焦滤镜设计方案分析（面向剪辑师/后期师）

**执行摘要：** 本方案面向影视过场场景（如大光板虚焦到实景切换）提出Unity URP光斑变焦（Bokeh Zoom Blur）滤镜的实现设计。我们比较了**纯屏幕空间径向采样**与**结合深度/法线等信息**的多种方案优缺点，并推荐最适合剪辑师工作流的实现路径。最终方案提供直观易调的参数（如**强度Intensity、半径Radius、阈值Threshold、软膝SoftKnee、混合模式Blend Mode**等AE/DaVinci常用术语），同时支持调整光圈叶片数、旋转、色散等摄影效果，满足艺术家精细调控需求。报告中包含详细的采样算法原理、参数建议、示例伪代码，以及优化与常见问题排查指导，为工程实现和后期调试提供全面参考。

## 实现方案对比

| 实现方案                       | 优点                                                          | 缺点                                                          | 适用场景（剪辑师视角）                                       | 性能（相对）  | 建议采样数/分辨率           |
|----------------------------|-------------------------------------------------------------|-------------------------------------------------------------|-------------------------------------------------------|-----------|----------------------|
| **纯屏幕径向采样**         | 实现简单，无需深度等额外RT，只需对颜色缓冲径向迭代采样累加，易于快速集成。<br>适合快速增加运动感，简单过渡效果。 | 效果整体，对所有像素模糊一致，无法区分远近，散景形状难调节；采样不足或过大偏移易产生边缘折痕【27†L703-L711】。 | 需要快速过渡效果时使用，例如给整帧光源或高亮区域均匀模糊。         | 低        | 8~16 次；可用 1× 或 0.5×  |
| **深度分层可变半径**       | 借助深度生成CoC(弥散圆)，模糊半径随景深改变，可模拟焦前焦后效果。<br>对远景散焦处理更真实，适合层次感过场。 | 增加深度采样和CoC计算开销，需仔细处理前景遮挡；效果对近大物体不明显，需要软阈值避免杂色。 | 需要体现前景与远景景深差的场景，如模拟镜头前后焦的电影级DOF过渡。  | 中等偏高  | 每帧分层 12~24 次；可用 0.5× |
| **法线引导方向模糊**       | 结合法线可针对漫反射或镜面高光做单向或平面方向模糊，如水面反射或光晕拉丝。 | 需额外法线RT；只对特定材质方向有效，不适合全屏径向模糊；计算复杂度增加。       | 场景中具有明显方向性反射的物体，如镜面、金属，高光带有拉伸感。    | 中等      | 每条方向 8~16 次；可用 0.5× |
| **光源/高亮追踪（高质量）** | 首先提取明显光源/高亮点，对每个单独进行散景采样并合成，效果最真实。<br>支持多光带和镜头色差，适合专业电影调光。 | 需要多次采样合成（高亮提取、单独模糊、合并），性能开销很大。调参复杂，不适实时预览。  | 对画质要求极高的镜头光斑特效，如科幻光效、梦幻场景；或为单个打光做调色后期。 | 很高      | 高采样 32~64 次；使用 0.25× |

## 算法原理与采样策略

散景变焦的基本思路是以某个屏幕中心（Center）为轴心，对亮点进行径向模糊采样并累加合成。经典做法是从当前像素沿射线向外跳动，取若干样本并取平均（或加权），从而产生径向运动模糊效果【27†L679-L687】。当采样次数不够或位移太大时，图像边缘会出现折痕【27†L703-L711】，需要控制步长或增加样本平滑。采样策略可以采用：
- **均匀径向采样**：固定角度方向，像上面代码片段对一个方向连续采样，简单稳定。
- **黄金螺旋/随机分布**：在圆周上以Golden Angle旋转，类似X-PostProcessing库的散景实现【11†L490-L499】；或利用Poisson蓝噪分布随机采样多点，降低周期伪影。  
- **分层采样**：先在半径小范围内高密度采样，再在大半径稀疏采样，加权叠加，可在保持效果的同时减少总样本。  
采样时结合**亮度响应**（Threshold+SoftKnee）只对高亮点加重权重，相当于先做Bloom高光提取，然后对高光像素进行径向模糊，效率更高且结果更符合剪辑师聚焦习惯。同时可考虑**曝光调节**（先对图像整体做曝光增益）来控制散景对暗部的影响。

## 光斑形状控制

【25†embed_image】光斑形状可通过模拟镜头光圈特性调节。Unity URP景深Bokeh模式提供**叶片数(Blades)**、**叶片曲率(Curvature)**、**叶片旋转(Rotation)**等参数【31†L85-L92】。图示不同叶片数和曲率下的散景形状变化：叶片数越少，光斑轮廓越明显多边形；曲率越低，多边形边缘更明显；旋转角可调整多边形朝向。对后期师来说，这些参数类似AE/DaVinci镜头光斑滤镜中的“形状”、“平滑”选项。实际实现中，常用方法是在采样时应用**权重函数**来塑造形状，如对采样角度做非线性映射或在合成时使用光圈遮罩，满足不同光圈效果需求。

## 色散与颜色处理

为模拟光学色散，可在采样时分别对R/G/B通道做微小偏移：例如给红色样本点偏移略小的半径、蓝色略大的半径，从而出现色边【30†L5-L11】。也可在混合阶段对不同通道应用不同权重。此外，整体色调可使用**曝光增益**参数处理，即在取样前对图像应用伽马或曝光调整，使得暗部更亮后再进行阈值筛选和模糊，这种做法与摄影中控制动态范围类似。剪辑师可配合AE/DaVinci色轮使用，先提亮想要出现散景的区域。

## 高亮保留与混合模式

散景效果主要聚焦在图像高亮部分。因此通常先应用**亮度阈值(Threshold)**，只对亮度高于阈值的区域进行散景模糊。**软衰减(SoftKnee)**用于平滑阈值边缘，避免阈值硬切换带来的不自然。实现上可先在高亮处生成一张Mask或单通道权重图，再基于该权重进行加权模糊。混合时，常用**加算(Add)**模式直接叠加散景层；**屏幕(Screen)**模式可避免过曝，把亮点混合得更柔和；**叠加(Overlay)**可保留更多高光细节。推荐提供3种模式供后期师尝试不同观感。

## 与URP管线的集成

在URP中，此效果可作为后处理特效实现。对URP14+版本，官方提供**FullScreen Pass Renderer Feature**支持全屏Shader，只需在Renderer添加FullScreenPass并绑定材质【18†L27-L35】【39†L138-L142】。对早期URP，可用**ScriptableRendererFeature + ScriptableRenderPass**方式挂载自定义后处理（编写C#类注册到Renderer，参考官方手册）。特效通常放置在渲染后期/Post-Process阶段。需要采样时要先在Shader中声明对应的色彩缓冲（BlitSource）和深度法线纹理。注意启用后处理Volume系统，在Volume Profile添加自定义组件，使其可在编辑模式下可视化调节参数。对计算量大的高质量方案，也可考虑Compute Shader多线程实现，但需在RenderPass里调用ComputeKernel。

## 关键实现示例（伪代码）

```hlsl
half4 PS_BokehZoom(Varyings i) {
    float2 uv = i.texcoord;
    // 计算从中心指向当前像素的向量
    float2 dir = (uv - _CenterUV);
    // 最大偏移比例（可乘以图像对角线长度）
    float maxR = _BlurRadius;
#ifdef USE_DEPTH
    // 若使用深度影响则根据深度调整半径
    float depth = SAMPLE_DEPTH(_CameraDepthTexture, i.texcoord);
    maxR = lerp(_MinRadius, _MaxRadius, depth);
#endif
    float2 step = dir * (maxR / _SampleCount);
    
    half4 sum = 0;
    for(int s = 0; s < _SampleCount; ++s) {
        float2 sampleUV = uv - step * s;
        half4 col = SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, sampleUV);
        // 亮度权重（P3加权）
        float lum = dot(col.rgb, float3(0.2126, 0.7152, 0.0722));
        float weight = saturate((lum - _Threshold) / _SoftKnee);
        
#ifdef APPLY_CHROMATIC
        // 色散：对R/G/B通道使用微偏移
        float3 shift = float3(-_Dispersion, 0, +_Dispersion) * step;
        col.r = SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, sampleUV + shift.rg).r;
        col.b = SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, sampleUV + shift.ba).b;
#endif

        sum += half4(col.rgb * weight, 0);
    }
    sum /= _SampleCount;

    // 与原图混合
    half4 orig = SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, uv);
    if (_BlendMode == 0)      return orig + sum;                  // 加色（Add）
    else if (_BlendMode == 1) return 1 - (1 - orig) * (1 - sum); // 屏幕（Screen）
    else if (_BlendMode == 2) {                               // 叠加（Overlay）示意
        half4 outColor = orig;
        if (orig.r < 0.5) outColor.r = 2*orig.r*sum.r; else outColor.r = 1 - 2*(1-orig.r)*(1-sum.r);
        if (orig.g < 0.5) outColor.g = 2*orig.g*sum.g; else outColor.g = 1 - 2*(1-orig.g)*(1-sum.g);
        if (orig.b < 0.5) outColor.b = 2*orig.b*sum.b; else outColor.b = 1 - 2*(1-orig.b)*(1-sum.b);
        return half4(outColor.rgb, 1);
    }
    return orig + sum;
}
```

该伪代码演示了**采样循环**、**高亮加权（亮度阈值/软阈值）**和**色散处理**的基本流程。实际使用中，可将其置于URP的FullScreen Pass Renderer Feature或后处理RenderPass中。注意在C#侧设置全屏Pass要求采样的Buffer（Color/Depth等）。如果启用法线信息（USE_DEPTH宏），则可加入法线光照计算进一步调整模糊方向，如使用表面法线与视角向量决定采样方向，用于镜面高光效果。

## 优化建议与排查清单

- **多级/分辨率策略**：对高半径散景，可先低分辨率做粗模糊（如0.5×），再叠加到原图，保留细节同时大幅减小采样量。不要直接全分辨率高采样。  
- **采样分布优化**：在片元Shader中引入随机偏移（可用蓝噪纹理或Hash函数）并结合时间累积，可打散采样结构化伪影，减少闪烁。尽量避免固定角度冲击相邻帧同步。  
- **并行与多通道**：若硬件支持，可用**MRT**同时计算RGB三个通道偏移（实现色散）或将多次采样分布在多条渲染通道，提高效率。Compute Shader也可用于大规模并行采样。  
- **性能剖析**：使用Profiler检查Shader占用。应监测采样数、分辨率、宏分支等对帧时间的影响。对目标60FPS系统，先对较重的高质量模式做分辨率降级，并提供快速预览模式。  
- **防止噪点/条纹**：如果效果出现随机颗粒或竖条噪点，可尝试增加样本数或使用双线性滤波平滑采样结果。开启URP的抗锯齿或临时模糊也能减少闪烁。  
- **边缘伪影**：注意处理屏幕边缘像素，有两种方式：一是对UV进行clamp，使超出屏幕的采样停留在边界；二是循环采样时检测超界逻辑并降低权重。避免黑边或重复边缘光斑。  
- **调试工具**：可增加一个“只显示散景层”的Bool参数帮助调试，只输出采样累积部分，无需合成原图。还可临时调高对比度或色彩饱和度显示散景分布。  
- **参数敏感度**：警惕“阈值”过低导致全屏散焦、“阈值”过高导致无效果；采样次数过低出现斑驳，过高性能下降。LeafCurvature(叶片曲率)过低易形成图像锐角，可根据需求选择。  
- **典型问题**：若效果在特定移动/场景中失效，检查是否正确传入了深度/法线贴图。Shader中的宏分支（USE_DEPTH、APPLY_CHROMATIC）需与C#同步。若报错可验证pass类型为‘Post-processing’或自定义Renderer是否正确启用。

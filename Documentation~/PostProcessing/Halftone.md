# 网点（`Halftone`）

ImageProcess 的**半调网点**：把画面按亮度转成规则网屏（拜耳有序抖动 / 圆点 / 方点 / 菱形 / 线条），
用来做漫画网点、波普海报、报纸杂志印刷、铜版画排线这一类观感。

设计上它排在 `渐变映射` 后面用最省事（ramp 管颜色、网点管墨量），但**单走也能用**：不依赖 ramp，
靠自己的输入窗口 + 墨色/纸色就能出图。

## 0. 名字与分工

- 枚举 `Halftone`（值 58，追加在 `GradientMap` 之后），面板图标「网点」，显示名数组第 58 项。
- 刻意不叫「半调」：`SkyTyndall` 的「抖动模式」里已经有一项叫「半调」（光线上的点阵增益），
  同一个面板里两个不同含义的「半调」会分不清。
- 与包内既有"点点"效果的分工：`DitheringCustom`（视频游戏）是噪声/贴图阈值 + 色阶量化；
  `BlueNoise`（蓝噪色块）是单元马赛克 + 玻璃/海报化；`SkyTyndall` 的半调只是光线修饰；
  `ToonMap` 只管色调映射。**几何网屏**（有序抖动 + 面积调制网点）此前没有，是本效果的内容。

## 1. 和 `渐变映射` 的配合

运行时按图层列表顺序执行（`ImageProcessPass.cs:163,239`），新增图层追加在末尾
（`ImageProcessStackVolumeEditor.cs:872`），所以"先点渐变映射、再点网点"天然就是 ramp → 网点 的顺序。

| 用法 | 图层链 | 说明 |
| --- | --- | --- |
| 彩色漫画 | 渐变映射（色阶数 4~6 压成平涂色板）→ 网点（**遮罩原色**或**叠墨**） | 颜色来自 ramp，网点只做印刷质感 |
| 黑白漫画 / 波普海报 | 网点**双色**（墨黑纸白） | 画面只剩两色；ramp 可选（预设「风格/配合渐变映射」就是给串联准备的） |

## 2. 墨色、纸色与四种合成

- **墨色** = 图层通用的「颜色」（`_LayerColor`），面板上就是「墨色」那一行；
- **纸色** = `parameters2.xyz`，面板上一行颜色；
- **合成**（`parameters2.w`）：

| 值 | 名称 | 公式（`c` = 覆盖率，`img` = 原图） | 用途 |
| --- | --- | --- | --- |
| 0 | **叠墨**（默认） | `lerp(img, ink, c)` | 把墨色印在画面上，没有墨的地方保持原图 —— 单走最稳，暗部出网点 |
| 1 | 双色 | `lerp(paper, ink, c)` | 经典波普/黑白漫画，画面只剩两色 |
| 2 | 乘算 | `img * lerp(paper, ink, c)` | 保留原图明暗，只染色（报纸/套印） |
| 3 | 遮罩原色 | `img * lerp(paper, 1, c)` | 网点里保留原图颜色，网点外压成纸色（配合 ramp 的彩色漫画） |

注意默认值是**叠墨**而不是规划稿里写的"遮罩原色"：遮罩原色在纸色为白时是恒等变换（什么都不发生），
不符合"一加上就该像网点"的预期；叠墨 + 墨黑 + 白纸开箱即用，且亮部完全不动原图。

**方向**：`parameters1.z`（面板「暗部上墨」）默认 1，即**暗部墨多**（正常印刷/漫画方向）；
关掉则亮部墨多（反白/负片）。

## 3. 五种模式与数学

单元的约定：cell 是单位正方形 `[-0.5, 0.5]²`（面积 1），"覆盖率"= 单元内被墨覆盖的比例。
`cell`（参数）是**一个网点的边长，单位是屏幕像素**；拜耳模式下它是**矩阵一格**的边长。

| 模式 | 半径 / 阈值 | 面积律 |
| --- | --- | --- |
| **圆点** | `r = sqrt(tone/π)` | 严格成立到 `tone = π/4 ≈ 0.785`（此时 `r = 0.5`，相邻点相切）；再往上把半径从 `0.5` 桥接到 `√2/2`，`tone = 1` 时盖满整格 |
| **方点** | `r = 0.5·sqrt(tone)`（切比雪夫距离） | 覆盖率**恒等于** tone（边长 `sqrt(tone)`） |
| **菱形** | `r = sqrt(tone/2)`（`|dx|·ratio + |dy|`） | 严格成立到 `tone = 0.5`（此时相邻菱形连成链，传统印刷的 50% 跳变点）；再桥接到 `r = 1` |
| **线条** | 带宽度 `= tone` | 覆盖率**恒等于** tone |
| **拜耳** | 阈值 `(M + 0.5)/n²`，矩阵 `M` 是 2×2 / 3×3 / 4×4 / 8×8 | 矩阵均值**恒等于** tone（量化到 `1/n²`） |

- 拜耳矩阵由 `M(2n) = 4·M(n) + B`（`B = [[0,2],[3,1]]`）生成 4×4 与 8×8，3×3 用通行的那张
  `0 7 3 / 6 5 2 / 4 1 8`；检查会验证它们是 `0..n²-1` 的**排列**（每个阈值恰好出现一次），
  4×4/8×8 的首行也与公开的表一致。
- **旋转**：屏幕转过 `angle`，所以格坐标 = 像素坐标**反向**旋转（`R(-a)`）。这里踩过一次坑：
  最初写成再次正向旋转，等于把网屏转了两倍，数值检查（"一格里的平均覆盖率必须等于 tone"）
  立刻抓到了（15°/30°/75° 全部偏到 0.42）。
- **网格抖动**：每个单元内的网点按 `hash(cellIndex)` 偏移，偏移量只跟整数格号有关，所以接缝处不裂。
- **柔化**：在阈值附近按 `softness`（单元比例）做线性过渡，用来压掉高频网点的锯齿与闪烁。
- 抗锯齿/柔化宽度在三种模式里都用同一个 `scale` 归一化（方点/线条 0.5、菱形 1、圆点 0.707），
  所以一个柔化值在各模式下手感一致。

## 4. 参数槽位（实现后的最终契约）

| 槽 | 内容 |
| --- | --- |
| `color` | 墨色（alpha 未用） |
| `parameters0` | x 模式(0..4), y 输入源(0..6), z 黑场, w 白场 |
| `parameters1` | x 单元大小(px, ≥1), y 角度(度), z 暗部上墨(0/1), w 柔化(0..0.5) |
| `parameters2` | xyz 纸色, w 合成(0..3) |
| `parameters3` | x 浓度上限(0..1), y 网格抖动(0..1), z 拜耳矩阵(0..3 = 2/3/4/8), w 保留 |
| `parameters4` | x 菱形比例(0.05..3), y 输出抖动(8-bit LSB), zw 保留 |

输入源与 `GradientMap` 同一套编码：0 亮度(Rec.709)、1 红、2 绿、3 蓝、4 最大值、5 平均值、6 饱和度。

shader 里自己声明全部 uniform（不经任何 include），所以 `check_all.ps1` 不会替它兜底；
24 种混合模式走共享 include `ImageProcessBlend.hlsl`。

## 5. Inspector

```
[✓] 网点                     ← 折叠行（含强度）
    模式 / 输入 / 黑场 / 白场
    暗部上墨 / 单元大小 / 角度 / 柔化 / 网格抖动
    浓度上限 / 合成 / 纸色
    [拜耳矩阵]       ← 只有拜耳模式
    [菱形比例]       ← 只有菱形模式
    抖动 / 墨色 / 混合模式
```

固定 15 行 + 条件 1 行；行数由 `GetHalftoneLineCount` 与绘制函数严格对应（有检查钉住，§7）。

## 6. 预设（5 组 15 个）

| 组 | 预设 | 要点 |
| --- | --- | --- |
| 漫画 | 黑白漫画 / 少年漫粗网 / 少女漫细网 | 圆点 + 双色，网点从 6px 到 11px 再到 3.5px，浓度上限 1 → 0.95 → 0.85 |
| 波普 | 波普圆点 / 丝网双色 / 海报方点 | 洋红叠墨、青+米白双色（带网格抖动）、黑+亮黄方点 |
| 印刷 | 报纸 / 杂志细网 / 菱形链网 | 报纸是 4.5px + 低浓度 + 抖动 + 输出抖动；杂志是细网低浓度叠墨；菱形在 15° 连链 |
| 线条 | 铜版画线条 / 木刻排线 / 斜线阴影 | 30°/75°/135° 的排线，分别用双色/乘算/叠墨 |
| 风格 | 复古拜耳 / 拜耳 4 阶 / 配合渐变映射 | 8×8 与 4×4 有序抖动（角度 0），以及给"渐变映射在上"准备的遮罩原色 look |

## 8. 尚未验证（需要实机看）

1. 五种模式与 15 个预设的**实际观感**（这套检查只能证明数学与接线正确，证明不了好不好看）；
2. **C# 与 HLSL 的逐像素一致**：这里没有 GPU 执行环境，只做了常量/公式 parity（§7），
   一旦 shader 与 C# 的写法出现"看起来一样但结果不同"的差别（例如精度、`frac` 负数行为），
   只能靠实机对比；
3. 运动时高频网点的闪烁/爬行，以及「柔化」的最优值（预设给的 0.05~0.25 是经验值）；
4. 与 `渐变映射` 串联的实际配合（色阶数 4~6 + 网点），以及「遮罩原色」在彩色 ramp 上的观感；
5. 与其它 ImageProcess 效果/URP 后处理（Tonemapping、SMAA 等）同时使用时的顺序影响；
6. 分辨率变化（Game 视图缩放、DLSS/超分）时"单元大小按像素"的稳定性；
7. 大面积平涂下拜耳模式的观感（会不会有可见的图案块）；
8. 与「透明背景」效果同用时的 alpha（shader 只改 rgb，alpha 原样透传）。

## 9. 后续可做

- **分色**：RGB / CMYK 各自一个角度（15°/75°/0°/45°）的网屏叠加，出真彩印刷的摩尔纹；
  v1 按决定先不做；
- **覆盖率曲线**：把图层的 `ramp` 字段当"网点扩大补偿"曲线用（横轴 tone、纵轴覆盖率），
  需要在 `ImageProcessRuntimeLayerBuilder` 里让 Halftone 层也烘焙 ramp（现在只有 GradientMap 烘焙）；
- **误差扩散**（Floyd–Steinberg）属于另一个家族，会破坏规则网点感，不在本效果里；
- 预设缩略图（现在只有文字菜单）。

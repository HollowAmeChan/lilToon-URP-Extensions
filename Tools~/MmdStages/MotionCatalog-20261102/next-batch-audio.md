## 文件与同步约定

- 动作库：`D:/Unity_Project/BREAK_URP/Assets/00动画/VMD动画/甜茶`。
- 每个作品目录新增一份 `BGM.wav` 和 `BGM来源.json`，均有 `.meta`；动作、表情、运镜和 README 原件不改动。
- WAV 为 48kHz、双声道、16 位 PCM；Unity 导入设置使用 PCM，保留立体声。没有做响度归一化或变速。转成 PCM 是为了制作兼容，并不恢复网站压缩前的音质。
- 已逐份验证可解码、采样数准确、非全静音，记录原音轨/输出 SHA256、作者原曲链接、实际下载来源、裁切样本位置及检查结果。
- 时长重新从 VMD 原始整数帧读取，不再对库存表的四舍五入秒数取整。此处长度采用动作、表情和运镜的最大末键帧 / 30。
- 已裁成动作片段，Sequence 的 BGM 时间偏移初始填 `0`。**39.6 秒等是整曲裁切点，不是组件音乐延时。**
- 六首按 README 帧号裁音的作品，仍须在 Scene 中听看一次，确认网站镜像没有前奏增删；两首用同动作预览定位的作品，也尚未在 WTD 上验证动作卡点。清单统一标注 `alignmentVerified: false`，不把“有音轨”当作“整片已验收”。
- `88888888` 与 `ハッピーミルフィーユ` 后续应提取仅含眼骨与 morph 的派生表情 VMD，保留原件；不能把身体 VMD 原封不动再作为一套启用骨骼驱动的 Face Player。
- 原始整曲、参考视频与网站元数据只放 Git 忽略的 `Temp~/NextBatchAudio-20261102/`，项目中只保存所需动作片段和精简来源记录。音轨来源记录不代表获得重新分发或商用授权。

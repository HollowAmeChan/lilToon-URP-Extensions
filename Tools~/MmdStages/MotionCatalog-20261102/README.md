## 下一步制作方式

1. 首批先做 Minskirt 和 Cry_For_Me，继续放在已有 `花吐电気通用动画/Scenes/`，复用角色、舞台、Rendering 和 Materials。
2. PV 中的音乐只提取为动作目录下的一份音频；先确认分段、起点和尾部，使用组件现有 BGM 偏移卡点，不创建第二套同步系统。
3. 换动作使用“更新素材（保留适配）”；有作者 sizing PMX 时指定它。没有对应尺寸参考的先测试，不宣布旧适配可直接通用。
4. 对实际非零 morph 做缺失检查；`facial.vmd` 中的 `両目` 等眼骨仍应应用，不能只取其 morph。
5. 用 360×640 / 30 fps 录整段验证，检查手指、手靠脸、脚底、IK 和衣物。确认后再按用户选择升档。

不会由此次库存扫描自动重建场景、调整用户灯光/滤镜、启动高质量渲染或重跑之前八支视频。

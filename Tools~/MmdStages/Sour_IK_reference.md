# Sour 1.02 IK 参考

来源：用户指定的 `Sour式初音ミクVer.1.02`。完整解压报告保存在 `E:/BaiduSyncdisk/大师/_完整动作_整理/_参考模型/Sour暄/Sour_IK_REPORT.md`。

两个 PMX 变体都包含 319 根骨骼和 131 个 morph，标准骨骼表无缺失。White 具备 11 个 IK 控制器：

| 控制器 | Target | Link 链 |
| --- | --- | --- |
| 左足ＩＫ | 左足首 | 左ひざ → 左足 |
| 右足ＩＫ | 右足首 | 右ひざ → 右足 |
| 左つま先ＩＫ | 左つま先 | 左足首 |
| 右つま先ＩＫ | 右つま先 | 右足首 |
| 左/右腕、肘、手 WIK | 对应 W 先骨 | 对应 W 骨 |
| 首WIK | 首W先 | 首W |

Black 还多一个 `キューブIK`。这说明适配不能只复制“左右脚”四个名字；动作可能写入手／肘／颈 WIK。HoIkConstraint 的脚部配置可直接按上述链建立，动作级 IK 开关仍由 `Weight/SolveEnabled` 控制。
